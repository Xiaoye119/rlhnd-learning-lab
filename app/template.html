启动方式与当前可用性
RLHND 官方仓库目前没有发布推理代码/权重。本页真实接入采用已发布的 HumanWAM-Goal。其官方环境为 Linux、Python 3.13、CUDA 12.8、Hopper SM90；本机 Windows / RTX 5060 Laptop 8GB 不符合该方案。
先在符合条件的机器按官方说明加载 checkpoint，启动 goalwam serve --checkpoint ...；将服务转发到本机的 8000 端口后，在本材料目录运行：
python serve_demo.py --upstream http://127.0.0.1:8000

uv run python serve_demo.py --upstream http://127.0.0.1:8000
# 然后访问 http://127.0.0.1:18765
