## 机制与界面验收

| 检查 | 观察结果 |
|---|---|
| 缓存默认场景 | W3 首次严格满足 v > Tᵥ，6 个窗口使用同一 β，前 3 个探测窗口计入回解 |
| 无合格 / 预标定 | 分别保留各窗口 β / 从开始使用外部 β |
| 接触几何 | −12 mm 时 signed=true、unsigned=false；5 mm 包含、5.01 mm 排除 |
| 未感测位置 | 未知预测从 6 改到 10，正确 MAE 始终 0.540；错误补零从 3.270 变为 5.270 |
| 顶点分配 | 非负、数值稳定；总和等于给定 F，包含 F=0 |
| 动作块 | 16×42×3；右手第 5 步开始无效时为 420/672 个有效关键点 |
| 参数修改 | 清空旧结果、标记待运行，防止旧结果与新参数混淆 |
| 作者视频 | EgoDex 三路各 3.2 秒；OpenTouch 三路各 10.8 秒；播放、暂停、切换与同步成功 |
| JSON 导出 | 浏览器下载后解析：动作块 16×42×3；服务 fixture 响应 [1,48,49]，明确带 test_fixture=true |
| 物理状态模板 | null 占位被阻止提交，页面提示填入 49 个有限数值 |
| 服务不可用 | 明确显示 503 未配置提示，推理按钮禁用；没有替代曲线 |

数学自动测试 5 项、代理协议自动测试 5 项通过。浏览器检查使用实际控件交互；图像上传经本地测试服务检查为纯 base64，响应图和导出完成。协议 fixture 是确定性构造数组，没有加载模型。

窄屏检查宽度 390 px，主文档没有横向溢出；导航允许横向滚动。报告中的宽表格在各自容器内滚动。

## 验证范围

内置浏览器仅允许 HTTP(S)，拒绝直接打开 file://；没有绕过该限制。单文件通过依赖检查确认图片、视频、脚本均内嵌，交互行为通过同内容的本地 HTTP 服务验证。普通浏览器的“双击 HTML”入口是交付使用方式，但本次未用内置浏览器直接验证 file:// 打开。

DPP 教学位移公式为显式约定 p(t+k)−p(t)，不是对未公开 packer 的逐位复现。已知复现缺口在报告 §9 和相关机制段落就地列明。
